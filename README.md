# Exploration Hough Transform

## Description
Ce projet est une application interactive permettant de visualiser et de comprendre l'algorithme de la **Transformée de Hough**. 

L'interface permet d'explorer étape par étape :
- La détection de contours (Canny).
- Le calcul de l'accumulateur (Espace de Hough).
- La dualité Point-Sinusoïde.
- L'extraction et le tracé des droites détectées.

## Installation

1. Assurez-vous d'avoir Python installé sur votre machine.
2. Installez les dépendances nécessaires via `pip` :

```bash
pip install -r requirements.txt
```

## Utilisation

Pour lancer l'application, exécutez la commande suivante dans votre terminal :

```bash
streamlit run hough_viz.py
```
